# 桌面工具版本检查与生命周期

当前显示、安装、升级和卸载策略见 [工具生命周期](tool-lifecycle.md) 与 [ADR 0006](adr/0006-cc-switch-tool-lifecycle.md)，按 CC Switch 的工具和平台规则执行，已替换此前 npm 优先和新装固定版本策略。

“检查更新”刷新安装分布、各入口版本与官方最新版。登录恢复后检查一次；窗口聚焦、恢复可见、托盘或 Dock 拉起、原生恢复、页面切换、空间切换时同步登录、账号/余额和工具信息。同一次动作的多个事件合并；同步期间的新事件保留一次后续同步。没有固定周期的工具检查或登录续期，用户停留不动时不轮询。

后台同步保留已有内容，仅修改发生变化的文本、属性及增删项目，不清空整页或替换整个工具行。保持滚动位置、焦点、展开的安装位置和菜单；更新数据后按钮使用最新上下文。首次加载、明确退出登录和切换到另一工具详情可以建立新视图。登录到期使用单次到期检查；正在安装、升级、卸载时仍跟踪该任务进度，完成后同步结果。

已安装和未安装分组；无法运行与未安装分开。显示版本、已识别来源、当前路径和其他安装。未知来源不贴“原生程序”等渠道徽章。安装说明直接来自后端执行方案。

新装跟随各工具的官方安装器或 npm latest，部分官方脚本失败时转 npm。已有安装按终端入口及原渠道更新。多处安装时展示每处的版本和运行状态，并在升级确认中列出具体目标及命令。确认后的入口/方案变化要求重新确认。npm 的 Node 约束在检查和执行前核验。执行成功还需检测到实际版本达到检查目标；不把退出码 0 当作成功，不自动降级。

版本与安装列负责安装和更新；接入列独立描述连接。未安装且无连接显示“—”，保留连接但程序缺失时继续显示保存的连接状态。安装、升级、卸载与接入共用工具锁；DuMate 两种账号类型共享应用锁。

全部升级只计入可自动更新的工具，按确认时保存的各工具计划依次执行。单工具明确失败后继续，无法确认状态时停止队列。可以停止当前操作并跳过后续项目；退出登录不再启动下一工具。

“更多 → 卸载”先列出具体安装；确认前只读。npm、Homebrew 和已知原生布局分别验证归属，执行时重新推导并核对计划。只移除选定程序或其包，保留配置、数据及接入记录。卸载后确认该入口消失，并说明是否仍有其他安装；未知来源提供手动说明。

公开版本元数据请求不发送账号或配置；并发上限 4，连接超时 4 秒、单请求超时 12 秒、响应上限 2 MiB，只允许 HTTPS 重定向。Windows 的版本检测、安装和清理辅助进程继续使用 CREATE_NO_WINDOW。

隔离验证覆盖实际离线脚本执行及 npm 兜底、安装恢复、同渠道升级、包归属、确认失效、配置保留、卸载结果核验和界面 IPC。真实 Windows 安装、签名安装包和各工具最新版 Agent 接入验收分别报告。
