# 桌面用量统计

本地实现日期：2026-11-05。桌面侧新增“用量统计”页：上方图标筛选、四项汇总和趋势，下方仅保留分页请求日志。后端需同时发布 Core 和 WebAPI 新接口后才能线上使用；本次没有部署或推送。

## 查询范围

当前登录账号、当前空间、本设备曾接入工具的全部历史 API Key。服务端从 `api_tokens` 按 user/workspace/device/source/tool 取 ID 集合，不用本地当前连接或 `client_key_bindings` 的当前 Key 推导历史。包含旧 Key、过期、停用、软删除 Key 和已断开的工具；不包含其他设备、其他空间、其他用户或第三方直连。历史范围依赖平台保留的 Key 归属元数据和请求日志。

CLI/桌面沿用同一个设备标识。设备标识由 Rust 读取，不由网页传入；服务端还校验桌面登录客户端、当前账号/空间和实时日志查看权限。此页按 Key 的签发设备归属统计；Key 被复制到别处使用时不会据此改变归属。

无历史 Key 返回空态，不能回退到全空间查询。取消接入无需向服务端同步状态。切换账号/空间和退出登录会清除页面数据及游标；迟到的旧响应会被丢弃。

## 页面与计算

- 时间：当天、近 24 小时、近 7/14/30 天，以及日历 + 日期/时刻自定义范围；默认近 30 天。日界和时间显示固定北京时间。自定义结束时间可以跟随当前时刻，实际查询和后续翻页使用同一截止点；刷新时再推进。取消草稿不会查询。时间预设不提供“全部”。
- 筛选：全部 / 历史工具图标分段切换。按用户最新要求移除“工具 / 模型”级联下拉和“全部状态”筛选；页面始终查询全部模型及全部状态，日志仍展示每条请求的模型与状态。翻页沿用已应用的筛选和时间截止点。
- 四项汇总：总费用、总请求数、平台记录的总 Token、缓存读取命中率。点击卡片切换趋势指标，趋势图始终展开。所选跨度不超过 24 小时按小时展示，超过 24 小时且最多 90 天按日展示，超过 90 天按月合并（缓存命中率由月累计分子、分母重算）。
- 明细：时间、工具、模型、费用、输入/输出/缓存读取、状态码、耗时、首字延迟。缺少延迟时显示“—”。
- 日志每页 20/50/100 条，默认 20；使用稳定游标前后翻页。分页栏显示当前完整筛选范围的“共 N 条”，翻页与调整每页条数不重算汇总；未能读取汇总时显示“共 — 条”。每页选择框使用统一边框、圆角和单个下拉箭头。
- 费用保留平台微额度并按整数累加；总费用卡片四舍五入显示两位小数，明细及趋势提示保留六位小数。不猜测 USD/CNY，也不按模型单价重算。与浏览器流水单位一致。

服务端一次返回同条件按小时或按日可加统计，客户端求和并绘图，不下载全量日志。总 Token 直接使用日志 `total_tokens`，不重复加缓存。缓存命中率为累计缓存读取 / 累计规范化输入；规范化输入逐条取 `max(total_tokens-output_tokens, input_tokens, 0)`，兼容缓存包含方式及旧 total 缺失的保守回退，分母为零显示“—”。不会对每天百分比取平均。

现有 metrics rollup 缺少缓存写入和日志结果等必要维度，因此首版日桶与明细使用同一个日志过滤条件；不要宣称日桶已经改为现有 metrics 预聚合表读取。支持跨月自定义查询，Core 对同条件同 Key 范围日桶缓存 30 秒（最多 512 项），独立缓存日期/状态范围内全设备 Key 的工具/模型聚合（最多 512 项），客户端不设置固定刷新周期或本地时间节流。进入页面、切换空间由共享 `sync.js` 事件入口合并触发，先同步登录与空间再读取用量；筛选变化与“刷新”按钮直接读取。窗口获得焦点、原生激活、恢复可见和历史页面恢复只同步账号 / 空间 / 工具，不主动读取用量；若同步发现当前空间已改变，仍按空间切换重新读取。请求期间的重复同步通知合并成一次后续读取，离开页面后不追加读取；切换身份或空间时丢弃旧通知与旧响应。同一账号与空间刷新时保留已有汇总、趋势和日志；返回后按请求 ID 与趋势档位原位更新，保留焦点和横向滚动，柱图以 320ms 过渡（跟随系统减少动态效果设置）。趋势区域保持固定高度；刷新失败保留上次成功数据并提示错误。汇总和日志各自保留其成功查询的时间快照，等待新响应时切换指标或缩放窗口不会误用新时间范围重绘旧数据。空闲时不轮询。尚未测量生产查询负载；未来可在保持契约下迁移到维度完整的预聚合数据源。

## 接口

`POST /api/client/usage/logs` 和 `POST /api/client/usage/buckets`，以 Client Session Bearer 鉴权。公共请求字段：

```json
{
  "workspaceId": "7",
  "deviceId": "native-device-id",
  "startTime": 1791129600000,
  "endTime": 1793620000000,
  "tool": "codex",
  "model": "",
  "status": "ALL",
  "cursor": null,
  "page": 1,
  "pageSize": 20
}
```

用户身份和允许工具集合由服务端确定；不接收任意用户或 Key ID 列表。响应包含 tools（工具及历史 Key 数）、buckets（日统计）、groups（全设备历史 Key 在该日期/状态条件下按工具/模型的可加汇总，仅 buckets 接口返回）或 items（分页流水），以及 nextCursor/page/pageSize/asOf。Key ID 和金额使用字符串，避免整数精度丢失。服务端只投影页面所需公开字段。`groups` 不受已选工具/模型影响，保留接口筛选能力；当前页面已按用户要求移除工具 / 模型聚合页签，不使用 `groups`；服务端字段保留兼容。

Rust 命令 `desktop_usage_logs` / `desktop_usage_buckets` 还校验请求的账号和空间，查询前后检查共享登录及当前空间。旧服务端返回 404 时页面明确提示服务未启用，不伪造零用量。

## 趋势图缩放修复

趋势图改为按容器内容宽度重新计算 SVG 坐标，保持等比绘制和 12px 坐标文字。窗口尺寸变化仅重绘图表，不重新请求用量。此前固定 `720 × 210` 画布配合 `preserveAspectRatio=none` 导致横纵缩放不一致；新增浏览器回归测量文字的屏幕变换矩阵，覆盖 700/900/1280/1920px 宽度并检查无额外请求。

## 小时趋势

按起止时间的实际跨度自动选择粒度：`endTime - startTime <= 86400000` 返回 `granularity=HOUR`，否则为 `DAY`。小时桶新增毫秒时间戳 `bucketStart`，`date` 继续使用北京时间日期。小时桶从所选开始时刻起每小时一档，末档可不足一小时；零长度范围保留一档。查询结束点仍包含在内，恰好位于结束点的请求并入最后一档，24 小时范围最多 24 档，不产生第 25 档。空小时由前端补零；跨零点以日期标注。金额、请求数、Token 和缓存率都从同一组完整范围桶汇总，不使用当前页明细估算小时分布。

需要配套更新 Core/WebAPI。旧服务端缺少小时元数据时仍显示其汇总，图表提示小时趋势暂不可用；不把日统计当小时统计绘制。本次没有部署后端。

## 请求详情抽屉

点击日志行任意位置，或使用 Tab 定位时间按钮后按 Enter / 空格，可打开右侧请求详情。展示当前记录的北京时间、工具、空间、模型、请求 ID、状态码、Key 名称、输入 / 输出 / 缓存读取 / 缓存写入 / 总 Token、平台费用合计、首字延迟与总耗时。请求 ID 完整换行且可选中复制；缺少性能数据时显示“—”。输出速度以总输出 /（总耗时 − 首字延迟）估算，限成功、输出至少 100 Token、首字有效、生成时间至少 100ms 的记录。输入和总 Token 均保留平台记录口径，不重新累加缓存。当前接口未提供费用分项，因此仅展示真实费用合计，单位与平台流水一致。

抽屉直接使用当前页已获授权的公开记录，打开详情不额外查询或引入轮询。支持关闭按钮、Esc、遮罩点击、键盘焦点约束，以及关闭后返回对应日志按钮；长字段在窄窗口内换行。事件刷新保留已打开的详情，同一请求更新时同步字段；切换页面、空间、账号或退出登录即关闭并清空详情。

## 日期选择状态

“结束时间跟随当前时刻”开启时，日历保持编辑开始日期；结束时间输入只读，不自动切换到结束日期编辑，也不禁用整张日历。选中起止日期及区间高亮保持可见，只有未来日期等不可选项变淡。结束日期 / 时刻在打开面板和日历交互时更新，不添加定时器。明暗主题回归检查选中日期的文字对比度与继续选择开始日期、关闭跟随后编辑结束日期的行为。
