## 结论

CC Switch 的使用统计有两条数据路径：**本地代理转发请求记账**和**直接导入 CLI 本地会话日志**。后者不要求打开代理；“Sync Now”是扫描并导入本机日志。截图中的会话来源数据可以在未接管网络流量的情况下产生。代理路径要求启用本地路由、对应应用接管及请求记账。[官方手册](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/docs/user-manual/en/4-proxy/4.4-usage.md#L12-L49)

## 指标口径和限制

- **处理 token 总量** = 新鲜输入 + 输出 + 缓存写入 + 缓存命中；**缓存命中率** = 缓存命中 /（新鲜输入 + 缓存写入 + 缓存命中）。分母不是请求数。OpenAI/Codex 输入字段可能已经包含缓存，统计和计费会先规范化，避免再次重复计入；这不是“去除全部缓存后的实际付费 token”。[公式](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/services/usage_stats.rs#L47-L63)、[缓存输入计费规范化](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/proxy/usage/calculator.rs#L51-L115)
- **成本是估算金额，不是账单或实付费用**。按模型单价分别乘四类 token，再乘 provider 倍率；导入 session 使用倍率 1。支持自定义价格、预设及 models.dev 导入/可选自动同步；找不到价格的 Codex 行成本入库为 0，UI 将未定价显示为 Unpriced。订阅套餐月费、折扣、额度与此金额不能直接等同。[计费公式](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/proxy/usage/calculator.rs#L51-L118)、[session 定价](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/services/session_usage_codex.rs#L2478-L2500)、[未定价 UI 说明](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/docs/user-manual/en/4-proxy/4.4-usage.md#L110-L123)、[价格来源/自动同步](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/docs/user-manual/en/4-proxy/4.4-usage.md#L147-L202)
- **请求数**来自统计库中的请求记录（及其日聚合计数）。会话路径中，Claude 按 assistant message，Codex 按非重复计费事件；不能保证等同用户发言次数、任务数或账单请求数。**成功率**尤其要分源：Claude、Codex session 入库直接写 `200`，并没有观测真实 HTTP 状态，因此不能据此推断网络请求成功率。[Claude 入库](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/services/session_usage.rs#L1338-L1369)、[Codex 入库](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/services/session_usage_codex.rs#L2503-L2538)
- **代理 TPS** = 输出 token /（总耗时 − 首 token 耗时），仅输出至少 100 token、生成窗口至少 100ms 的明细参与；分组速度按总输出/总生成时间计算，并非逐请求速度平均。[实现](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/services/usage_stats.rs#L129-L163)
- **会话 TPS 是估算**，按日志时间戳得到总耗时（包含首 token 等待），仅输出至少 200 token、耗时至少 1 秒参与。当前源码也能从部分会话估算首 token 时间；与代理实测值分别计算，中位数分开保存，显示估算标记。手册仍说 session 没有首 token 时间，存在文档落后于源码的情况。[当前源码](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/services/usage_stats.rs#L136-L199)、[手册旧表述](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/docs/user-manual/en/4-proxy/4.4-usage.md#L125-L129)
- 日志没写出的 token、已删除或无法读取的会话、未知模型及协议差异均限制覆盖面。“精确解析”指读取日志中已记录的计数，不代表可以验证供应商账单。部分协议不报告缓存写入，统计可能偏低。[手册提示](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/docs/user-manual/en/4-proxy/4.4-usage.md#L60-L67)

## 同步、保留和恢复

自动扫描默认启动一次、后台每 10 分钟；使用页可选 5/10/30/60 秒，离开或隐藏页面回到后台周期；可以关闭自动扫描并仅手动同步。扫描使用互斥锁和增量游标。[后台实现](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/lib.rs#L1455-L1505)、[页面行为](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/docs/user-manual/en/4-proxy/4.4-usage.md#L34-L49)、[游标](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/database/schema.rs#L309-L325)

启动及周期维护会把 30 天前明细转入日聚合后删除；历史总量保留，但逐请求明细和 TTFT/TPS 无法从日聚合恢复。Codex 重建会备份数据库并重扫本地日志，已删日志不能重导入。[30 天调用](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/database/mod.rs#L152-L157)、[汇总实现](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/database/dao/usage_rollup.rs#L59-L62)、[性能排除汇总](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/src-tauri/src/services/usage_stats.rs#L129-L139)、[重建限制](https://github.com/farion1231/cc-switch/blob/ca58c0313360eae7c851fbd7553c1614c7af03e7/docs/user-manual/en/4-proxy/4.4-usage.md#L139-L145)
