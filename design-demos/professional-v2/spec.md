# Token Market 专业桌面改版
日期：2026-11-04

目标：支持工具增长后的查找、状态扫描与连接管理，保留安装、接入、打开、测试、重新接入、取消接入、账号空间、应用设置与帮助。

统一画布：1440×900；同时验证当前默认窗口 900×760 和窄屏 375×812。三方向都用 14 个真实目录工具；安装、状态、空间为明确标注的演示数据，不读本机凭据，不执行真实安装或测试。测试先说明可能收费。

受众：在多个 AI Agent 间切换的开发者、个人及团队用户。情绪：可靠、有秩序、少干扰。

用户补充原话：「logo帮我也重新设计下，之前的白底不好看，特别是常驻状态栏的时候」。每方向配一个新矢量 Logo，状态栏使用透明底单色图形，演示浅深两套菜单栏；后续正式实现使用 macOS template image。

假设：本次先做可点击设计初稿，选定后接入真实业务；分组是设计提案，并非服务端已有标签。账号余额不编造，只显示未加载或示例空间。

Form 五问：叙事是日常操作入口；近距离桌面阅读；温度稳重；首屏容纳 7–14 项；视觉母题来自安装/连接/测试三个独立状态，以及当前空间与已有连接计费空间的区别。
