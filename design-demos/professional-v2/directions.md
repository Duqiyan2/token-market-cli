# 六方向探索与入选
共同规格见 spec.md。当前秒数采样 S=33，Web 20 种得 14「斜切流体渐变」，East 12 种得 10「服部一成错位」。均已看样张。六格实际渲染见 screenshots/thumbs.png。

## A 精密管理台（入选 dir-1）
最佳设计师逻辑：Dieter Rams 的功能秩序，不声称复刻其作品。借：统一列基线、操作降噪、状态色只用在状态。主角：14 个真实工具标志与对齐的数据行。骨架：稳定侧栏 + 工具表 + 选择后详情抽屉。胆量：让重复字段成为有序列，放弃大卡片。Form：工具扩张要求一次扫过多种安装/连接状态。新 Logo 为简明 T 字标，模板图标无底板。

## B 工具收藏架（备选）
最佳设计师逻辑：Michael Bierut 的信息节奏，不声称其参与。借：顶栏大标题、等大标志、三列卡片。主角：工具标志。骨架：横向导航 + 无侧栏收藏架。胆量：把图标识别提到第一层。Form：用户先认工具再执行操作。

## C 分组列表（备选）
现实参照：Linear 官方 https://linear.app/docs/display-options ，已查看 refs/linear.png，其中有实际产品显示选项截图。借：分组、横线、左侧导航与内容分层，不使用发光营销视觉。主角：状态分组行。骨架：侧栏 + 分组列表。胆量：压缩卡片信息。Form：需要处理异常时先看待处理组。与 A 骨架接近，留备选。

## D 分栏工作台（入选 dir-2）
现实参照：Warp 官方 https://docs.warp.dev/terminal/windows ，已查看 refs/warp.png。此图为官方文档界面，未将其当作实际终端截图；借用官方证实的 split panes 结构，而非声称复刻终端视觉。主角：工具列表与对应配置同时呈现。骨架：窄导航轨 + 工具列表 + 常驻详情。胆量：深石墨与薄荷动作色；不做假日志或终端装饰。Form：管理连接时保持工具上下文，避免详情往返。新 Logo：交换双链，模板图标无底板。

## E 流体工作区（备选）
秒数轮盘 Web 14，已查看 skill assets/style-specimens/web/14-angled-fluid-gradient.jpg。借：色面划分与斜切分区；主角：工作区色面 + 列表。骨架：蓝色空间栏 + 工具平面列表。胆量：大色面。Form：空间决定新连接归属。但渐变对日常管理价值不大，因此不入选。

## F 轻快工具库（入选 dir-3）
秒数轮盘 East 10，已查看 skill assets/style-specimens/east/10-hattori-playful-offset.jpg。借：节奏不对称、块面疏密；不搬用巨字或海报装饰。还原降级：从海报转成桌面工具，取消装饰错位，保留导航与工具区不对称比例，不主张原风格 70% 以上还原。主角：真实工具图标与精选常用区。骨架：顶部导航 + 左分类栏 + 三列紧凑工具卡；独立详情弹层。胆量：将常用与发现分开，卡片保留呼吸。Form：支持工具越多，新工具发现与已接入工具使用需要不同入口。新 Logo：连接端口，模板图标无底板。

# 选择依据
A 扫描效率最高；D 处理深层配置最直接；F 工具发现与新手体验最好。三者骨架、密度、温度不同。B/C/E 保留在六格图中。等待用户选定，未改生产界面与托盘代码。
